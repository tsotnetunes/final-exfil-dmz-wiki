## How do you open a bank vault?

1. Find a Car Battery and use it to power the vault's card reader, which reports no power until you do.
2. Use the Bank Branch Vault Access keycard on the reader.
3. Read the paper note in the bank: it gives the first three digits of the code.
4. Try the last digit on the keypad until the door opens.

Players report opening bank vaults across Hajin [clm_82e276dd1672]. This is the method seen on several filmed runs [[src-gamerfuzion-gold-bar-route-2026-10-29]] [[src-gamerfuzion-orders-page-14-2026-10-30]]; the community map also calls it a code puzzle [[src-codmunity-hajin-map-2026-10-31]]. The note's digits differed between runs, so do not trust a code from a guide.
