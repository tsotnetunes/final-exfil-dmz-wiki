Natural Concealment is a camo event for Modern Warfare 4 that went live on Monday 16 Nov 2026, the same day as that week's patch [[src-infinityward-x-natural-concealment-2026-11-16]] [[src-mw4-season-1-patch-notes-2026-11-05]]. It is a grind for weapon camos rather than an event with its own map objective, and DMZ counts toward it.

## How does it work?
Each weapon class has its own set of challenges. Complete a class's challenges and you unlock the event camo for that class [[src-infinityward-x-natural-concealment-2026-11-16]].

## Do DMZ matches count?
Yes. Every challenge can be done in Multiplayer, DMZ or Warzone, and a challenge only has to be finished in one of those modes, not in all three [[src-infinityward-x-natural-concealment-2026-11-16]]. So a player who only plays DMZ can earn every reward.

## What is the final reward?
Finishing the challenges for every weapon class unlocks Woodfall, an animated Mastery Camo that works on all weapons [[src-infinityward-x-natural-concealment-2026-11-16]].

## When does it end?
The announcement gives no end date. The individual challenge tasks for each class are not listed in it either; check the Events tab in game. It runs beside [[joint-fire]] on Fridays, [[wager-match]] and the [[resupply-run-event]]. For DMZ's own camo tracks see [[dmz-camos]]; every dated event is on [[events]].
