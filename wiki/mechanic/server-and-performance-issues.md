## What happens to your gear if you crash?

If you crash or lose connection, the developers said you should be able to rejoin while that match is still running [[src-westie-dmz-ama-recap-2026-10-11]] [[src-gamerfuzion-dmz-60-players-2026-10-12]]. If you cannot get back in, players report losing the run's loot, as in any failed exfil [clm_004ae083916b] [[src-gfinity-dmz-tech-issues-2026-10-22]]; what a failed run costs is on [[death-and-loss]]. We have found no announcement of compensation or restored items for gear lost to crashes (1 Nov 2026). Newer single reports: a crash during extraction left the Operator dead on rejoining [clm_ca6990fa1a25], and lag got one player kicked with the Operator lost [clm_fd065cd2a969].
