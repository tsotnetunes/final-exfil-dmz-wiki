# Timesaver: Modern Warfare 4 on Steam Deck
URL: https://timesaver.gg/blog/modern-warfare-4-steam-deck-can-you-play-handheld
Captured: 2026-11-02 (published 26 Sep 2026)
Trust: third-party

Facts taken, in our words:
- A stock Steam Deck on SteamOS cannot start the game; the block is software, not power.
- Reasons given: the RICOCHET kernel driver does not run under Proton or Wine (from compatibility trackers), and the Deck lacks the Windows checks behind TPM 2.0 and Secure Boot.
- Windows 11 handhelds (ROG Ally X, Legion Go, MSI Claw) can meet those requirements, it says.
- DMZ is not discussed by name.
